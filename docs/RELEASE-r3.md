# 3.6.0 中文修复包 r3：中文恢复与语言选择

修正 r2 管理器构建漏执行中文转换、播放器打包遗漏 Locale 的问题。改为内嵌中英双语资源，并同时提供播放器 gettext 语言文件，构建不再依赖事后视觉树替换或轮询汉化。

播放器的设置窗口顶部、管理器窗口顶部都有 **界面语言 / Interface language** 下拉框：简体中文、English、跟随系统。默认简体中文，不因英文 Windows 自动变成英文。设置会保存；完全退出播放器和管理器后重新打开生效。选择语言不会自动退出正在播放的窗口。

播放器与管理器共用 portable_config/interface-language.json，仅保存界面偏好。不会修改视频、字幕、模型文件名、AI 参数、已保存的配置名称或快捷键。选择“跟随系统”时，中文系统使用简体中文，其他系统使用英语。

管理器页签、全局设置、配置方案、处理链、组件、帮助文字、导入导出和确认弹窗使用双语资源；播放器菜单、设置分类、常用参数名称及 150 条主设置说明有中文。技术标识（TensorRT、RIFE、参数名、路径等）和外部程序原始日志保留原文。已有自定义右键菜单/快捷键文本不被覆盖，因此用户自己写入的菜单文字不会随此选择自动改写。

## 安装
这是基于已有 AnimeJaNai 3.6.0 的累计修复包，包含 r2 的 FPS、Player UI 参数接收及稳定性修复，不需要另装 r2。不是 AI 模型完整安装包。

完全退出 mpvnet.exe、mpv.exe 和 AnimeJaNaiManager.exe；备份原播放器目录，将更新 ZIP 的内容完整解压到原目录并覆盖同名文件。不要只复制一个 EXE 或 DLL。

不覆盖 mpv.conf、input.conf、animejanai.conf、现有模型、Sharp1/2K/4K 预设或缓存。默认语言从内嵌设置提供，不会用打包时的偏好文件覆盖你的选择。

## 验证
只有语言资源生成、管理器中英界面构造/选择保存、播放器语言控件、解析器、配置往返、r2 原生与 Lua 回归均通过才打包发布。构建证据、语言覆盖统计、截图和 SHA-256 位于 build-info/language-r3。随发布提供实际构建使用的 UI 源码包。

原生播放器库、FPS 脚本及更新器与 r2 逐字节相同。本次没有重新测试用户 RTX5080 的 AI 性能、Player UI 账户或实际服务器，继续标记为预发布。
