# AnimeJaNai 3.6.0 中文修复包 r2

这是已有 3.6.0 中文版的增量修复覆盖包，不是上游 3.6.1，也不是完整 AI 模型安装包。

## 安装
完全退出 mpvnet.exe / mpv.exe / AnimeJaNaiManager.exe，先复制原安装目录作为备份，再将 ZIP 内容解压到原播放器根目录，允许覆盖同名文件。不要只拷贝 libmpv-2.dll：本包同时提供该原生构建所需的依赖 DLL。
本包不覆盖你的 mpv.conf、input.conf、animejanai.conf、Sharp1 / 2K / 4K 预设、AI 模型或引擎缓存。基础版本须已安装原来的 3.6.0 中文覆盖包；只安装本增量包不能把全新的英文版完整汉化。

## 本次修改

- Ctrl+J：读取原生 vo-presented-frame-count，通过真实时钟计算实际 FPS；只显示实际/目标数字，不显示“跑满”或丢帧行。移除 time-pos 回调计数假装实际 FPS 的旧算法。刚打开、跳转后暂显示 --，暂停显示 0。
- 原生计数只累计 VO 提交的新视频帧，不把重复刷新、OSD 重绘当作新帧；它不是显示器扫描输出的硬件测量值。
- 外部播放：保留 mpv --{ ... --} 的每集独立字幕、标题、起播参数及播放列表起始位置；需要这些参数的调用使用独立进程，防止旧单实例转发丢失参数。针对 Unicode 和多个字幕路径做回归。
- 原生字幕稳定性及 WASAPI 热插拔 COM 生命周期修复，包含固定版本的 libass 和配套 DLL。
- 保留中文 Manager；合入 0.6.0 的 RIFE Ensemble 设置 yes/no 保存修复。
- 更新器合入按“已安装组件版本”选包以及快捷键原子迁移修复；不再拿最新正式版组件覆盖当前预发布版。
- D3D11 两个降噪 shader 的未初始化通道修复。
- 各播放器进程隔离 AI 状态日志；引擎监控仅在活动 AI 播放时运行，日志缺失/空写入不再当成构建成功。
- Ctrl+U 改为打开本中文仓库发布页，不再启动会覆盖汉化与原生计数器的官方整包自动更新，也不会因更新检查失败误报“已经最新”或强制退出播放器。原组件安装功能仍保留。

## 验证与限制

build-info 内包含来源提交、逐文件 SHA-256、回归结果和构建来源。Windows CPU 测试覆盖 24/48 FPS、半速、慢滤镜开/关丢帧策略、暂停重绘、跳转、短生命周期音频查询、重复退出、Lua 数值采样，以及实际 mpvnet 命令行/IPC 集数字幕切换。
历史候选包 slow-filter 测试曾假定启用丢帧时也必须输出全部 12 FPS；现拆成关闭丢帧的严格吞吐控制和默认丢帧的瓶颈测试，不把处理上限当成实际输出帧率。

没有你的 Player UI 实际启动参数、视频服务器和 RTX5080 硬件，因此不能宣称已验证你那条播放链接或全部 GPU 行为。已修复并测试播放器这一侧的参数接收问题，但 Player UI 自身是否也传错 URL/字幕仍需实际调用才能确定。
上游 3.6.0 仍为预发布版；Manager 0.6.0 的相关修复已合入。inference 0.9.0 / TensorRT 11.3 是配套运行时升级，本次未单独混装，保留已有 3.6.0 的 AI 组件与缓存。

## 回退与源码
保留旧安装目录备份即可完整回退。不要把旧、新原生 DLL 任意混搭。
来源以 build-info/provenance.json 为准：主仓库 main 保存补丁、测试和打包流程，source 分支保存中文播放器；更新器的实际补丁后源文件也包含于 build-info/sources。
