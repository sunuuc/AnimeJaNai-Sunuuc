# AnimeJaNai 3.6.0 中文修复包 r4

本包是累计修复包，包含 r2 的真实 FPS/Player UI 参数修复与 r3 的中英语言资源，无需先安装 r2/r3；仍以已有 AnimeJaNai 3.6.0 完整安装目录为基础。

## 本次重点
- 管理器语言选择从窗口顶部移入“全局设置”，不再长期占据所有页面顶部。
- AI 档位切换改为单一控制器：日志隔离、起播档位、引擎构建等待和快捷键切换不再由多个脚本互相重建滤镜。
- 快捷键一次请求只发送一次有效档位切换；快速连续按键合并为最后一次，短暂忙碌会有限重试，不要求用户重复狂按。
- 起播在 AI 状态确认前只由本控制器临时暂停，确认后恢复；移除 file-loaded 后再次套默认档的竞争。不会用自动拖进度条掩盖问题。
- 仅在“用户本来就暂停，并且主动切换档位”时做一次 0 秒精确刷新；正常播放绝不周期性 seek，因此不会反复冲刷音频/解码管线。
- 旧 r2/r3 的日志隔离和引擎监控脚本变成惰性兼容文件，避免旧安装覆盖后仍留下重复观察器和轮询。
- 对旧 input.conf 中 `apply-profile upscale-on; script-message aji-slot N` 的危险组合运行时只覆盖对应按键，不修改用户文件；从而兼容旧配置同时消除“先重建后切槽”的竞争。

## 隐藏问题保护
切集/结束文件会取消旧定时器；状态日志按进程隔离且必须完整、匹配当前请求才算成功；初始化等待有上限，超时会解除脚本自己的暂停而不是永久卡住；检测到两套未标识 AI 滤镜或旧 VapourSynth AI 链时不会静默叠加第二套。

## 安装
完全退出 mpvnet.exe、mpv.exe、AnimeJaNaiManager.exe，备份原目录，然后把 ZIP 内容完整覆盖到原目录。不要只替换一个脚本或 DLL。

不会覆盖 `mpv.conf`、`input.conf`、`animejanai.conf`、模型、Sharp1/2K/4K 预设和引擎缓存。语言选择仍保存为独立偏好。

## 验证范围
Windows CI 必须通过：播放器/管理器中英界面与配置往返、Player UI 多集字幕参数、真实 FPS 原生计数器、Lua 控制器状态机（起播、单次切换、快速按键合并、失败重试、暂停刷新、旧按键兼容、结束清理）及实际 mpv Lua 运行检查，全部通过后才允许发布。

CI 没有用户的 RTX 5080 和 Player UI 实际账户，因此不能伪称已做该硬件/服务器的现场验证；但 r4 专门针对用户报告的事件竞争和起播状态机进行修复与回归。
